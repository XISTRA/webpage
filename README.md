# XISTRA

Página de próxima apertura, estática y preparada para GitHub Pages.

Incluye el logo de XISTRA, Airbeat para el título y Quantico para el texto. Las fuentes se sirven localmente. El fondo anima triángulos y conexiones, respeta la preferencia de movimiento reducido y pausa la animación al ocultar la pestaña.

## Publicación

Sube estos archivos al repositorio. En GitHub Pages selecciona la publicación desde la rama `main`, carpeta `/ (root)`. No necesita instalación de dependencias ni compilación. Las rutas relativas permiten usarla tanto en un dominio propio como en una ruta de repositorio.

## Vista local

Ejecuta `python3 -m http.server 8000` en esta carpeta y abre `http://localhost:8000`.

## Recursos

- `assets/logo.svg`: logo facilitado por XISTRA.
- `assets/fonts/Airbeat.otf`: fuente facilitada por XISTRA.
- `assets/fonts/Quantico-Regular.ttf`: descargada del [repositorio oficial de Google Fonts](https://github.com/google/fonts/tree/main/ofl/quantico). Licencia incluida en `assets/fonts/Quantico-OFL.txt`.
- `temporal/`: originales; la página utiliza las copias en `assets/`.
